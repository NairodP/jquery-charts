01 · Données

Utilitaires génériques jquery-core

Ces fonctions ne dépendent pas du DOM. Elles prennent des entrées explicites, conservent les valeurs nulles et retournent de nouvelles collections afin de pouvoir préparer les données avant n'importe quel moteur de rendu.

Entrées interactives

Locale, fuseau et précision

Actualisation immédiate

Le même instant UTC est volontairement proche de minuit : changer le fuseau doit faire apparaître le changement de jour, tandis que la locale change l'ordre des nombres et des dates.

Nombres : locale et précision

Unités : conversion déclarée

defineLinearUnit · createUnitConverter · convertChartDataValues

Le convertisseur ne connaît que les unités enregistrées. Il refuse une unité inconnue au lieu de supposer une conversion identité.

Échelles dynamiques

Par défaut, une valeur invalide lève une erreur pour éviter un résultat silencieusement faux. Le mode 'null' est disponible quand l'application veut l'assumer explicitement.

Nouvelles capacités jquery-highcharts

Les exemples suivants utilisent le composant public <chart>. Les boutons appellent ses méthodes publiques ; les événements capturés par la page sont affichés sous les graphiques.

Une série en colonnes affiche l'énergie sur l'axe gauche et une spline affiche la température sur l'axe droit. Survolez le graphique : chaque ligne du tooltip conserve son unité propre.

2

Thème Highcharts

[theme]

Le thème est fusionné avec les options générées : couleurs, fond, titres, axes et légende sont injectés sans réécrire le provider.

3

Option de rendu autoritaire

[renderedOption]

Cette option Highcharts est rendue telle quelle : elle montre le cas où une application possède déjà une configuration moteur complète.

4

Chargement et données absentes

isLoading · loadingLabel · noDataLabel

Les deux états sont distincts : le chargement affiche un message d'attente, tandis qu'un tableau vide affiche le libellé no-data.

5

Organizer et visibilité immuable

organizer · organizerState

Les boutons simulent une sélection externe de séries. Le provider original ne change pas ; seule la vue effective est recalculée.

6

Synchronisation de groupe

group · groupSync="all"

Les deux instances partagent le même groupe. Déplacez la souris sur un graphique pour synchroniser le tooltip ; utilisez une sélection de zoom horizontal pour synchroniser les extrêmes X.
