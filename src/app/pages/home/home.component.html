Une API unifiée pour
vos bibliothèques graphiques

Avec Jquery-Charts, vous pouvez changer de bibliothèque de graphiques sans réécrire vos données métier ni vos composants Angular. Cela vous évite de refaire les mêmes branchements pour chaque bibliothèque et vous donne une base commune pour les séries, le chargement, les données absentes, tout en proposant des fonctionnalités avancées suppémentaires et en laissant les API natives disponibles quand il le faut. Son écosystème ne s’arrête pas aux graphiques : l’Organizer permet de gérer les filtres et les regroupements et offre, plus largement, une personnalisation complète de vos vues, tandis que Jquery-Table reprend une configuration proche pour les tableaux.

Une seule API, plusieurs moteurs

import { ChartComponent }
  from '@oneteme/jquery-highcharts''@oneteme/jquery-echarts''@oneteme/jquery-apexcharts';

  type="bar"
  [config]="{
    series: [{ data: { xField: 'month', yField: 'value' } }]
  }"
  [data]="data"
></chart>
