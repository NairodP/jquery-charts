jquery-organizer / documentation

Un menu pour laisser l’utilisateur construire sa vue.

jquery-organizer fournit le menu de configuration et l’état des choix utilisateur. Il ne modifie pas automatiquement votre graphique : votre composant doit appliquer les événements au modèle de données.

Voir l’API complète ↗

Avant de commencer

Installer et importer

La librairie attend Angular 16.1 ou supérieur, Angular Material/CDK 16 et @oneteme/jquery-core. Le composant est standalone ; dans un composant standalone, importez directement OrganizerButtonComponent. Dans un module Angular classique, utilisez OrganizerButtonModule. 

npm install @oneteme/jquery-organizer @oneteme/jquery-core

import {{ '{' }} OrganizerButtonComponent {{ '}' }} from '@oneteme/jquery-organizer';

@Component({{ '{' }}
  standalone: true,
  imports: [OrganizerButtonComponent],
{{ '}' }})

02 · Intégration

Le principe en trois morceaux

01

Décrire la vue

OrganizerConfig déclare les choix proposés dans le menu. Il ne contient pas vos données et ne construit pas les séries ou lignes de votre composant hôte.

02

Conserver l’état

OrganizerState contient les choix courants. Le parent le conserve et le repasse au composant.

03

Appliquer la vue

Le parent écoute viewChange et applique l’état reçu à ses données, son graphique ou son tableau. La traduction dépend du modèle utilisé par votre composant hôte.

03 · Avec un composant hôte

Relier le menu à votre vue

Le bouton Organizer ne connaît ni votre graphique ni votre tableau. Votre composant parent reçoit l’état, l’applique à son modèle et recharge ses données si nécessaire.

Pour une intégration avec un graphique, le package fournit aussi des adaptateurs pour le modèle OrganizerChartConfig. Ils sont indépendants d’un renderer précis, mais votre application reste responsable de produire les données et la configuration attendues par le composant utilisé.

À retenir : OrganizerConfig configure le bouton. Il ne remplace pas la configuration de votre tableau ou de votre librairie graphique.

import {{ '{' }}
  buildOrganizerChartBinding,
  handleOrganizerChartEvent,
  OrganizerChartConfig,
  OrganizerButtonEvent,
{{ '}' }} from '@oneteme/jquery-organizer';

  private viewConfig: OrganizerChartConfig = this.getViewConfig();
  organizer = buildOrganizerChartBinding(this.viewConfig);

  onOrganizerChange(event: OrganizerButtonEvent): void {{ '{' }}
  const result = handleOrganizerChartEvent(
    event,
    this.viewConfig,
    this.organizer
  );
  this.organizer = result.binding;
  if (result.shouldRefetch) this.loadViewData();
{{ '}' }}
<organizer-button
  [config]="organizer.config"
  [state]="organizer.state"
  (viewChange)="onOrganizerChange($event)">
</organizer-button>

<!-- Votre graphique ou tableau utilise ici son propre modèle. -->

04 · Exemple minimal

Un bouton connecté à votre état

La configuration ci-dessous suffit pour afficher un menu de champs. Ajoutez les autres blocs uniquement si votre écran les utilise.

readonly organizerConfig: OrganizerConfig = {{ '{' }}
  fields: [
    {{ '{' }} id: 'sales', label: 'Ventes', visible: true {{ '}' }},
    {{ '{' }} id: 'orders', label: 'Commandes', visible: true {{ '}' }},
  ],
{{ '}' }};

organizerState: OrganizerState = {{ '{' }}
  visibleFields: ['sales', 'orders'],
{{ '}' }};
<organizer-button
  [config]="organizerConfig"
  [state]="organizerState"
  (viewChange)="organizerState = $event.state">
</organizer-button>

04 · Choisir les fonctionnalités

Ce que vous pouvez exposer

fieldsAfficher ou masquer des indicateurs.
xFields / yFieldsChanger la dimension et la mesure.
groupsChoisir une clé de regroupement.
slicesProposer des filtres chargés à la demande.
templatesPréparer des vues nommées réutilisables.
showExportAfficher Export, avec visuel et/ou données selon les callbacks fournis.
showPreferencesAfficher le menu Préférences pour éditer, sauvegarder ou effacer une préférence.
showActionsAfficher Actions pour copier le visuel ou basculer en plein écran.
